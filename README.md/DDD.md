# Documento Detallado de Diseño
El documento describe el diseño, la estructura, y las decisiones tomadas durante el desarrollo de mi pagina web.
# Diseño de la pagina web

# Descripcion de las paginas:

-index.html: Se trata de la página principal del sitio web
-about.html: Contiene la informacion personal, además de un par de imagenes( sacadas al azar de internet).
-net.html: contiene los enlaces a las páginas creadas por  los compañeros de clase.
topic.html: contiene el tema elegido para la asignatira, en mi caso he escogido el efecto mariposa.
degree.html: Contiene la informacion sobre el grado universitario ademas de un link que lleva a la página de la asignatura de fundamentos de la  ingenieria informatica.
fii.html: Contiene informacion sobre la asinatura de fundamentos de la ingenieria informatica, como asignaturas y una breve descripcion de la asignatura.

# Diseño visual:

El diseño de la página web esta basado en colores oscuros en el fondo y un color clarito en el texto para resaltarlo. Además todas las páginas contienen un estilo muy similar para seguir una misma dinámica.
Los colores, en su mayoría son azules de diferentes tonos y blancos para el texto, el fondo tiene un fondo azul oscuro y en las partes donde hay contenido estan resaltadas con siluetas semitransparentes. La tipografia de la letra es "Poppins" ya que es facil de leer, Los títulos tienen un tono de azul mas claro para que lllamen más la atención.
Para darle mas dinamismo las siluetas donde esta el contenido tienen animacion para que cuando pase el cursor por encima resalte aún más.

# Estructura de las paginas

La estructura de las páginas es lo mismo en todas, se componen de un header, donde incluye el menu principal con los links que llevan directamente a cada uno de los apartados de las paginas, un main, donde va el contenido de cada página y un footer, donde incluye el titulo del proyecto para cerrar visualmente la página. 

# Problemas durante el diseño
Los problemas durante la creación de la página web no han sido grandes, principalmente, han sido mal direccionamiento de enlaces  lo que impedia que enlazase bien las paginas.Otro problema que tuve fue con las imagenes ya que no sonseguia que se viesen en la página pero finalmente lo solucioné cambiando lasn rutas de enlace de las imágenes. Por último otro pequeño problema que tuve fue la creación de estilos, al no tener mucho conocimiento sobre css cada página tenía estilos muy distintos lo que hacía que la página no fuese visualmente estética por lo que tuve que cambiar los estilos varias veces y ayudarme de internet para la paleta de colores hasta conseguir uno común y elegante.

# Conclusión
La conclusión sobre este trabajo es que he aprendido el estructuramiento y la organización basica de una pagina web, lo que me permite tener una base minima para la creacion de futuras páginas webs.
En cuanto al tema de fallos y complicaciones en el desarrollo no han sido una gran cosa, todos se han podido solucionar de manera sencilla buscando informacion de internet, la mayor complicación para mi ha sido el estilo de la página ya que al no tener mucha idea sobre estilos al principio no daba con el estilo adecuado para que la página fuese elegante y visual.
